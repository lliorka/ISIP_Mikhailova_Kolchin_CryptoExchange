# УП.01.01 — CryptoExchange

**Тема:** «Проектирование и разработка базы данных для платформы по обмену криптовалют и цифровых активов».

Учебный проект для двух участников. Реализация: WPF / C# / .NET Framework 4.8 / Microsoft SQL Server.

## Состав проекта
- `CryptoExchange.sln` — решение Visual Studio.
- `CryptoExchange/` — WPF-приложение.
- `db/schema.sql` — создание БД, 8 связанных таблиц, ограничения, каскадное удаление и демонстрационные данные.
- `res/` — ресурсы приложения.
- `docs/` — распределение задач, сценарии проверки и заготовка отчёта.

## Быстрый запуск
1. Установить Visual Studio 2022 с компонентом «Разработка классических приложений .NET».
2. Установить Microsoft SQL Server и SQL Server Management Studio (SSMS).
3. Открыть `db/schema.sql` в SSMS и выполнить скрипт от имени пользователя, имеющего право создавать БД.
4. Открыть `CryptoExchange.sln` в Visual Studio.
5. В `CryptoExchange/App.config` изменить `Data Source` на имя своего SQL Server. По умолчанию используется `(localdb)\\MSSQLLocalDB`.
6. Восстановить NuGet-пакеты: `DocumentFormat.OpenXml`, `ClosedXML`, `PdfSharp`.
7. Собрать решение (`Build → Build Solution`) и запустить проект.

## Начальные учётные записи
После выполнения SQL-скрипта создаются:
- Администратор: `admin` / `Admin123`
- Пользователь: `user` / `User123`

Пароли демонстрационных пользователей хранятся в виде PBKDF2-хеша. При первом запуске приложения можно зарегистрировать собственные учётные записи. Не используйте демонстрационные пароли в реальных системах.

## Функциональность
- регистрация и авторизация с ролями `User` / `Admin`;
- PBKDF2-хеширование паролей, проверка формата пароля, капча после трёх ошибок;
- смена пароля;
- пользовательский просмотр активов, кошельков, заявок и операций;
- административная работа с таблицами БД через DataGrid (просмотр, поиск, сортировка, добавление, редактирование, удаление);
- график объёма заявок по статусам;
- экспорт отчётов в DOCX, XLSX и PDF;
- две темы оформления с сохранением выбранной темы;
- подтверждение выхода и удаления.

## Структура БД
`Users`, `Assets`, `ExchangeRates`, `Wallets`, `ExchangeOrders`, `Transactions`, `WalletEntries`, `AuditLog`.

Основные связи: пользователь 1:N кошельки и заявки; актив 1:N кошельки, курсы и заявки; заявка 1:N операции; операция 1:N движения кошельков; пользователь 1:N записи аудита (при удалении пользователя автор аудита становится NULL). Удаление пользователя каскадно удаляет его кошельки и заявки; связанные с заявками операции удаляются каскадно. Для остальных связей используются ограничения внешних ключей, чтобы не допустить удаления используемого актива.
