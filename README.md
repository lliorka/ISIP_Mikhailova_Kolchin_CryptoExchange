# УП.01.01 — CryptoExchange

**Тема:** «Проектирование и разработка базы данных для платформы по обмену криптовалют и цифровых активов».

Реализация: WPF / C# / .NET Framework 4.8 / Microsoft SQL Server.

## Начальные учётные записи
После выполнения SQL-скрипта создаются:
- Администратор: `admin` / `Admin123`
- Пользователь: `user` / `User123`

Пароли демонстрационных пользователей хранятся в виде PBKDF2-хеша. При первом запуске приложения можно зарегистрировать собственные учётные записи. Не используйте демонстрационные пароли в реальных системах.

## Функциональность
- регистрация и авторизация с ролями `User` / `Admin`;
- PBKDF2-хеширование паролей, проверка формата пароля, капча после трёх ошибок;
- смена пароля;
- пользовательский просмотр активов, кошельков, заявок и операций;
- административная работа с таблицами БД через DataGrid (просмотр, поиск, сортировка, добавление, редактирование, удаление);
- график объёма заявок по статусам;
- экспорт отчётов в DOCX, XLSX и PDF;
- две темы оформления с сохранением выбранной темы;
- подтверждение выхода и удаления.

## Структура БД
`Users`, `Assets`, `ExchangeRates`, `Wallets`, `ExchangeOrders`, `Transactions`, `WalletEntries`, `AuditLog`.
