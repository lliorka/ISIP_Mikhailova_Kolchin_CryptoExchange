## 1. Цель работы
Разработка WPF-приложения по теме курсового проекта с подключённой базой данных из восьми таблиц, разграничением ролей и средствами администрирования.

## 2. Виды выполненных работ
1. Анализ предметной области обмена криптовалют и цифровых активов.
2. Проектирование структуры БД и установление связей.
3. Создание таблиц, ограничений и демонстрационных данных в SQL Server.
4. Разработка WPF-проекта и подключение БД.
5. Реализация регистрации, авторизации, ролей, проверки паролей и капчи.
6. Разработка пользовательского и административного интерфейсов.
7. Реализация CRUD, поиска, сортировки и фильтрации.
8. Реализация смены пароля, тем оформления и диаграммы.
9. Реализация экспорта отчётов DOCX, XLSX и PDF.
10. Тестирование, размещение проекта в Git и подготовка защиты.

## 3. Схема базы данных
Вставить скриншот диаграммы из SSMS. Таблицы: Users, Assets, ExchangeRates, Wallets, ExchangeOrders, Transactions, WalletEntries, AuditLog.

## 4. Реализация приложения
Вставить скриншоты авторизации, регистрации, капчи, личного кабинета, панели администратора, CRUD, диаграммы, экспорта и смены темы.
