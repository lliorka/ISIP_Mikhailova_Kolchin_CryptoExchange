# План проверки приложения перед защитой

| № | Проверка | Ожидаемый результат |
|---|---|---|
| 1 | Запустить `db/schema.sql` | Создана БД и 8 таблиц, связи и демонстрационные строки |
| 2 | Войти как `user` | Открывается личный кабинет, видны заявки пользователя |
| 3 | Войти как `admin` | Открывается панель администратора |
| 4 | Ввести неверный пароль 3 раза | Появляется капча; без правильного кода вход не выполняется |
| 5 | Зарегистрировать пользователя с пустыми полями | Выводится сообщение о заполнении |
| 6 | Зарегистрировать пароль без цифры/заглавной буквы или с кириллицей | Выводится сообщение о требованиях к паролю |
| 7 | Зарегистрировать существующий логин | Регистрация блокируется |
| 8 | Сменить пароль с неверным старым паролем | Изменение не выполняется |
| 9 | Сменить пароль с корректными данными | Пароль обновляется в виде PBKDF2-хеша |
| 10 | Выбрать таблицы в панели администратора | Данные соответствующей таблицы загружаются |
| 11 | Добавить/изменить запись и сохранить | Изменения сохраняются либо показывается причина ограничения |
| 12 | Удалить запись | Запрашивается подтверждение; действуют FK и каскадные правила |
| 13 | Использовать поиск в админ-панели | Строки фильтруются по первому текстовому полю |
| 14 | Открыть диаграмму | Отображается количество заявок по статусам |
| 15 | Экспортировать DOCX/XLSX/PDF | Файл создаётся по выбранному пути |
| 16 | Сменить тему и перезапустить приложение | Выбранная тема сохраняется |
| 17 | Нажать выход/закрытие окна | Запрашивается подтверждение |

## Ограничения учебного стенда
Демо-приложение не выполняет реальные криптовалютные операции и не подключается к биржам. Экран администратора предоставляет универсальный DataGrid для учебного CRUD; ограничения PK/FK/CHECK/UNIQUE обеспечиваются SQL Server.
